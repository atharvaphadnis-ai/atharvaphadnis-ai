## 🚀 About Me

Hey there! I'm **Atharva**, an 8th-grade student, developer, maker and technology enthusiast from India.

I love turning unusual ideas into real-world projects. Whether it's building an AI-powered application, writing a backend in Go, developing Python tools, designing websites or experimenting with microcontrollers, I'm always working on something new.

I believe age shouldn't limit innovation. I started exploring technology because I wanted to understand how things work — and eventually build my own versions of them.

### What I do

- 💻 Develop applications, developer tools and open-source software.
- 🧠 Explore Artificial Intelligence, LLMs and AI agents.
- ⚙️ Build embedded systems, Arduino projects and robotics.
- 🚁 Experiment with DIY drones and flight controllers.
- 🌐 Develop web applications and backend systems.
- 🔬 Participate in science exhibitions and hackathons.
- 🌱 Learn something new and build something useful every day.

### A few things I've worked on

**LocalBase** — A lightweight self-hosted backend platform with REST APIs, SQL editor, data grid and real-time WebSockets.

**OLEDAnimator** — An Arduino library for non-blocking OLED animations, designed for memory-constrained microcontrollers.

**Arduino Fly** — A DIY quadcopter project using multiple Arduino Nano boards and NRF24L01 wireless communication.

**AetherLink RC Translator** — An ESP32-S3-based universal RC receiver and protocol translator.
